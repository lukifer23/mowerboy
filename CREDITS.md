# Credits

## Game

MowerBoy — original game code, illustrated and fallback vector machines, grass engine, audio graph, yards, and UI.

## Illustration

Title lawn, garage portraits, all fourteen top-down mower sprites, all eight vacuum sprites, grass textures, the red barn, and environmental objects were generated as original, unbranded artwork for this project. HUD icons, resilient machine fallbacks, furniture/floor/debris art, and live wheel, brush, deck, exhaust, suction, and material animation layers are drawn at runtime from original project code.

The durable generation brief, inventory, processing rules, and automated validation contract are recorded in [`docs/ASSET_PROVENANCE.md`](docs/ASSET_PROVENANCE.md).

No trademarked manufacturer marks are used. All machine names, including Sidekick and Meadow Ranger, are original.
