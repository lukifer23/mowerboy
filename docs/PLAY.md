# Play guide

Short words you can read aloud.

## Mowers

| Picture name | What it is |
|---|---|
| Sprout | Little push mower. Slow. Small. Buzzy. |
| Backyard | Everyday riding mower. A good first ride. |
| ZipTurn | Spins around fast. Wide-ish deck. |
| Yard King | Tractor with a bag in back. Steady. |
| WideBoy | Huge deck. Slow turn. Lots of grass at once. |
| Farmhand | Blue farm tractor. Chunky. |
| Storm | Big rumble. Heavy. |
| Night Owl | Lights for evening. |
| Sidekick | Quick purple stand-on mower. |
| Meadow Ranger | Wide front-mounted mower. |
| Garden Scout | Compact green tractor. Easy in tight yards. |
| Utility Mate | Sturdy orange utility tractor. |
| Field Giant | Big red field tractor for long passes. |
| Pivot Ranger | Articulated front mower that bends through turns. |

Every machine is open from the first visit. Swipe, pick the one that looks fun, and tap it to mow.

## Yards

Home Yard, Flower Beds, Winding Park, Soccer Field, Meadow, Farm Lane, Neighborhood, Hillside, Orchard, Autumn, Community Park, Grand Estate, Creekside Cabin, School Green, County Fair, Moonlight Park, Big Acreage, Tractor Field, Lakeside Park, and Forest Clearing.

**New yard** makes a fresh place every time.

**Free mow** grows grass back. Rain pickups add a full shower and grow more grass only in Free mow, so normal-yard progress never goes backward.

## Sparkles on the lawn

| Color-ish | What happens |
|---|---|
| Turbo | Faster, higher engine note |
| Wide | Bigger deck for a bit |
| Rain | A cheerful shower; more grass in Free mow |
| Magnet | Sparkles fly to the mower |
| Rainbow | Colorful machine |
| Birds | Friends nibble nearby grass |
| Mulch | Thick grass and leaves go easily |
| Lights | Evening glow |

None of these are required. They are treats.

## Vacuums and rooms

Bright Upright, Cyclone Clear, Quick Stick, Trailercan, Workhorse, Roundabout, Hall Keeper, and Floor Rider are all open immediately.

Clean the Living Room, Kitchen, Playroom, Bedroom, Hallway, Dining Room, Sunroom, Mudroom, Workshop, Classroom, Library, or Community Hall. Hold one finger where the vacuum should go. Dust, crumbs, cereal, hair, pet fur, leaves, confetti, tracked dirt, and sawdust disappear through the real intake. The Finish wand cleans any awkward leftovers.

## Buttons

- House — home
- Pause bars — rest, then Go
- Speaker — quiet / sound
- Wand — finish leftover grass
- Check — you did it! Again or Yards
